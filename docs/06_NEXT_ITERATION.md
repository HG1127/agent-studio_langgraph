## 第一条真实纵向闭环验收脚本

1. 测试用户进入“创建 Agent”，输入“计算并解释三个数据以及它们的总和”。
2. 已授权真实 LLM 返回合法 AgentSpec 草稿，前端展示目标、工具及停止限制。
3. 用户确认保存不可变版本，选择 add_numbers。
4. API 创建 Run；队列唤醒 Runner；LLM 使用结构化 tool call；工具在服务器执行并返回真实结果。
5. Run Events 展示时间戳、模型调用摘要、工具名称/参数校验结果与返回值（敏感内容按策略脱敏）。
6. 后台保存 checkpoint 和终态；刷新浏览器仍能查看进度和结果。
7. 断开模型授权、撤销工具权限、设置 max_tool_calls=0、模拟服务崩溃与重试，任务分别返回正确的失败/限制/恢复状态。
8. 在真实测试数据集上执行固定 Eval；通过后才能发布为非公开测试助手。

## 产品体验最小检查

- 新用户首页唯一主行动为描述需求；次级入口为模板和手动配置。
- 不向新用户暴露 Model Gateway、Token 预算、MCP Schema 等专业术语；在高级设置展开。
- 任务运行时展示做了什么、还剩哪些步骤、预计费用/已实际使用费用（不能编造数字）。
- 失败需要提供用户可操作的下一步，而不是只显示英文报错。
- 每一次配置变更可比较与回退；已发布版本不能被直接覆盖。

## 运行约束与发布阻断

- 没有 auth/RBAC/multi-tenancy 时不可公网部署。
- 没有可恢复 checkpoint 和幂等写入时不可上线长期工作流与外部写工具。
- 没有真实模型和真实工具验证时不可标记 G1 通过。
- 发生高风险工具权限绕过、跨租户信息泄露、重复写入或记忆跨域泄露时，阻断发布。
