# 产品与 UX 需求基线

## 定位

定位为零代码 Agent Operating Studio，不是聊天机器人外壳。用户群：零技术个人、业务人员、高级运营者、开发者。默认自然语言创建，高级配置渐进式展开，共享同一 AgentSpec。

## 主用户旅程

1. 登录 / 选择工作空间
2. 首页输入“我希望 AI 帮我做什么”，可附加资料
3. AI 结构化提取目标、工具、知识、成果、停止条件（必要时最多提问关键缺口）
4. 生成可预览/编辑的 AgentSpec 与用户可读说明
5. 授权模型、工具、知识来源（授权不足需明确提示，不能模拟成功）
6. 运行沙盒测试：显示计划、调用、来源、结果、错误、成本
7. 根据建议修改 → 创建新版本 → 再次评测
8. 用户发布 Web Agent，查看运行与管理版本

## 页面设计

| 页面 | 主内容 | 必要交互 |
| --- | --- | --- |
| 首页/创建中心 | 一句话输入、示例与模板、最近项目 | 新建 Agent、上传资料、选择模板 |
| 我的 Agents | 列表、分类、状态、版本、最近执行 | 查询、复制、归档、进入详情 |
| Agent 编辑器 | 对话构建、配置摘要、工具/记忆/知识面板 | 对话编辑、差异预览、保存版本 |
| 流程编排（P1） | 节点画布、节点参数、线路校验 | 连接/撤销/版本比较 |
| 运行中心 | 排队/进行/待审批/完成/失败等状态 | 暂停、取消、恢复、打开结果 |
| 运行详情 | Timeline、工具请求响应、来源、错误、费用 | 查看每一步，下载/复制结果 |
| 工具中心 | 工具目录、权限、MCP、连接器健康 | 连接、断开、授权、测试 |
| 知识与记忆 | 上传、引用、删除、记忆作用域 | 预览、管理、删除 |
| 测试中心 | 数据集、评分、版本对比 | 测试、回归、批准发布 |
| 发布中心 | 渠道、访问权限、上线版本 | 发布、停用、回滚 |
| 团队与安全 | 用户、角色、审批、审计 | 人员管理、审批决策 |

## 三种交互模式

A 简单模式：自然语言 + 三步确认（目标、数据工具、发布）。
B 高级模式：结构化配置和可视化工作流。
C 开发者模式：AgentSpec JSON、API、SDK、自定义受控工具。

三种模式为同一对象的不同视图。简单模式不得删除或覆写未展开的高级配置。

## 核心业务案例

- 公开资料研究：搜索事实、提供来源、标注不确定性、生成结构化报告。
- 知识库客服：读取已授权文件回答问题，不知道就说明。
- 数据分析：上传数据文件，在沙盒中处理并生成图表和结论。
- 办公流程：生成邮件草稿，获得审批后才允许发送（P0 内测阶段接入写工具）。

## 范围约束

P0 不含公共插件商店、付费市场、复杂多 Agent 或任意网站操作。正式上线前应完成账户/多租户/配额/审计，无法使用本地无认证原型替代。

## UX 指标

- 首次成功运行时间（TTFSR）：20 位非技术用户样本目标 ≥80% 在 15 分钟内完成标准任务。
- 创建转化率：从需求提交到保存 AgentSpec 的比例。
- 运行成功率：按任务种类及必备验收条件统计，不以“模型给了回复”判成功。
- 人工介入率、工具授权失败率、单次任务费用、重复调用率、误发率、NPS/任务满意度。
