# Agent Studio 验收矩阵

每项必须既有“用户能看到”，又有“后台真正执行”的测试证据；仅存在配置页面不算完成。

## 十二个 Agent 必备要素

| 要素 | 用户可见能力 | 后台必测证据 | 关口 |
| --- | --- | --- | --- |
| Goal/Task | 目标、成功条件、输出模板 | 不满足必备条件时 PARTIAL 而非 SUCCESS | G2 |
| Context | 指定资料与可追溯来源 | 不可检索未授权文档；来源/版本正确 | G2 |
| Tools | 工具目录、已授权能力 | 未授权工具拒绝；JSON Schema 校验 | G1/G2 |
| State | 进度、暂停、恢复、取消 | 崩溃重启后由 checkpoint 恢复 | G2 |
| Memory | 查看/修改/删除长期记忆 | 作用域隔离、删除后不可召回 | G2 |
| Planning | 可查看可调整子任务计划 | 计划有边界、重规划次数受控 | G2 |
| Tool Calling | 每次实际调用状态与输出 | 返回真实工具结果、失败可重试/区分 | G1 |
| Permissions | 批准/拒绝、权限信息 | 未获授权写操作 100% 被拦截 | G2 |
| Environment | 文件/浏览器/沙盒配置 | 非法文件/网络/进程访问被限制 | G2 |
| Observability | Trace、耗时、token/费用 | 任务-调用-事件关联；敏感信息脱敏 | G2 |
| Evaluation | 测试套件、对比、回归 | 固定用例可重复，发布基于门槛 | G2 |
| Stop Condition | 预算/时长/轮次/取消 | 所有边界场景触发真实中断 | G1/G2 |

## 八条核心端到端闭环

| ID | 用户旅程 | 完成证明 |
| --- | --- | --- |
| C01 | 注册/登录/工作空间 | 工作空间隔离与角色校验测试 |
| C02 | 自然语言创建 | LLM 生成合法 AgentSpec，不合法则解释并修复 |
| C03 | 连接工具与资料 | 真实授权、失效提示、断开后立即失权 |
| C04 | 真正运行 Agent | 模型按协议选择工具、工具实际执行、回显真实结果 |
| C05 | 上传文档并引用 | 来源证据可跳转，越权读不可行 |
| C06 | 权限与停止 | 高风险审批拒绝后不继续执行，预算强制终止 |
| C07 | 进度追踪/恢复 | Run、Event、Checkpoint 贯通，断线/重启恢复 |
| C08 | 质量评测/发布 | Eval 合格才能发布，版本历史可回滚 |

## 第一阶段最小验收（G0/G1）

1. 一条命令或明确步骤启动 Web / API。
2. 每个新增 API 都有契约校验与合理错误输出。
3. 没有模型密钥时明确返回“需要连接模型”，绝不返回模拟研究结果。
4. 真实模型连接时可生成受约束的配置与执行至少一个真实 Tool。
5. 每个 Run 存储状态、任务开始结束时间与执行事件。
6. 进程退出及取消场景必须有明确状态；完全持久化恢复可安排 G2，但不能声称已经具备。
7. CI 至少完成单测、类型检查、生产构建及秘密扫描。
8. 评审文档列出已实现、部分实现、待开发与风险。

## S3 发布门槛

- 20 名非技术用户的引导式测试：目标 ≥80% 在 15 分钟完成标准 Agent 创建及首次成功运行。
- 多租户及越权写操作测试零阻断缺陷；所有外部写操作必须可审计。
- 性能指标须在选定的并发和数据规模下制定并执行测试（不得虚构稳定性 SLO）。
- 灾难恢复/备份、凭据轮换、敏感数据删除及日志保留策略演练完毕。
- 平台管理员具暂停危险工具、任务或工作空间的能力。
